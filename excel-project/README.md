# Excel Sales Dashboard

**Tools:** Excel  
**Skills:** Data cleaning, formulas, pivot tables, dashboard creation

## 📘 Overview
This project demonstrates my ability to clean raw data, organize it into a usable format, and build a simple dashboard using Excel. The dataset included sales transactions with inconsistent formatting, missing values, and duplicate entries.

## 🔧 What I Did
- Cleaned and standardized the raw dataset  
- Removed duplicates and corrected formatting issues  
- Used formulas such as XLOOKUP, IF statements, and text/date functions  
- Built pivot tables summarizing sales by category, date, and product  
- Created a small dashboard with charts to visualize trends

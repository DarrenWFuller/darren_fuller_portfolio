# Python Hangman Script

**Tools:** Python  
**Skills:** Loops, conditionals, string handling, user interaction

## 📘 Overview
This project is a simple Hangman game written in Python. It demonstrates basic programming logic, control flow, and user input handling.

## 🔧 What I Did
- Created a word list for the game  
- Used loops and conditionals to track guesses  
- Displayed progress to the user after each guess  
- Checked win/lose conditions  
- Printed final results  

## 📂 Files Included
- `Hangman.py` – Python version of the hangman game (recommended file)
- `HangmanCode.txt` – Original text version of the code (kept for reference)
